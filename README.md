# Telegram-бот расчёта цены — версия для хостинга

## Что загружать
Загрузите `bot.py` и, если хостинг поддерживает зависимости из файла, `requirements.txt`.
`Procfile` можно использовать на хостингах, которые его поддерживают.

## Важно: токен
Не храните токен в коде и не публикуйте его. В панели хостинга добавьте переменную окружения:
- `BOT_TOKEN` = токен, полученный у @BotFather
- `FALLBACK_USD_RUB` = резервный курс, например `90` (необязательно)

## Команда запуска
```bash
python bot.py
```

## Автоматическая установка библиотек
`bot.py` проверяет наличие `aiogram`, `aiohttp` и `python-dotenv` и пытается установить отсутствующие через `pip` при запуске.
При этом на большинстве хостингов лучше указать `requirements.txt` или build-команду:
```bash
pip install -r requirements.txt
```
Автоустановка из работающего приложения сработает только если хостинг разрешает исходящие подключения и установку пакетов. Если хостинг не разрешает `pip install` во время запуска, установите зависимости через настройки сборки.

## Режим работы
Это Telegram-бот с long polling, поэтому нужен тариф/тип приложения, который поддерживает постоянно работающий worker/process, а не только статические сайты или короткие serverless-функции.
