# Telegram-бот расчёта цены с индивидуальными настройками площадок

## Возможности
- В расчёте выбирается ровно одна площадка.
- У каждой площадки собственные курс USD/RUB и комиссия.
- Курс и комиссия вводятся вручную и могут редактироваться.
- Добавление, просмотр и удаление площадок.
- Настройки сохраняются в SQLite и переживают перезапуск.
- Себестоимость принимается в рублях или долларах; результат показывается в обеих валютах.
- При старте бот проверяет зависимости и устанавливает недостающие пакеты как запасной вариант.

## Развёртывание
1. Распакуйте архив и загрузите содержимое папки проекта на хостинг.
2. Установите Python 3.12 (или совместимую версию Python 3.10+).
3. В переменных окружения хостинга задайте `BOT_TOKEN` — токен от `@BotFather`.
4. Команда сборки, если поддерживается: `pip install -r requirements.txt`
5. Команда запуска: `python bot.py`. Для хостингов с Procfile используется `worker: python bot.py`.

## Переменные окружения
- `BOT_TOKEN` — обязательно.
- `DATABASE_PATH` — необязательно, путь к SQLite-файлу. По умолчанию `bot_data.sqlite3` рядом с `bot.py`.
- `LOG_LEVEL` — необязательно, например `INFO`.

## Важно для хостинга
Нужен постоянно работающий worker/process, поддерживающий Telegram long polling. Убедитесь, что диск сохраняет SQLite-файл между перезапусками; на эфемерном диске данные настроек могут потеряться. Для нескольких экземпляров приложения используйте общую надёжную БД, а не локальный SQLite.

## Как пользоваться
1. Нажмите `⚙️ Настройки площадок` → `➕ Добавить площадку`.
2. Введите название, курс в рублях за 1 USD и комиссию в процентах.
3. Для изменения используйте `✏️ Изменить курс/комиссию`.
4. Для расчёта нажмите `💰 Рассчитать цену`, выберите одну площадку, валюту себестоимости и введите себестоимость и наценку.

## Формула
Цена продажи = себестоимость × (1 + наценка / 100) ÷ (1 − комиссия / 100).

Комиссия считается процентом от цены продажи. Курс площадки используется для пересчёта RUB/USD и не загружается автоматически из интернета.
